## 编译器原理表

| 阶段 | 输入 | 做什么 | 输出 | µASM 对应代码 |
|------|------|--------|------|--------------|
|**词法分析**(Lexer/Scanner) | 源文件字符串 `"$al > +"` | 跳过空白，按分隔符切出一个个 token | `["$al", ">", "+"]` | `scan_next()` / `Scanner` 类 |
|**语法分析**(Parser) | token 流 `["$al", ">", "+"]` | 看第一个 token 的首字符，决定这是什么指令 | `Store(reg=AL)` `IncPtr` `IncMem` | `compile_line()` / `nasm_line()` 里的 `if/else if` 链 |
|**代码生成**(Code Gen/Emitter) | 内部表示 | 查 x86 编码表，拼出机器码 | `0x88 0x02 0x42 0xFE 0x02` | `encode_line()` 里的 `emit_byte()` |


## 语法分析器 (Parser) 原理详解

| token 首字符 | µASM 指令 | 对应 x86 语义 | 解析动作 | 生成的内部表示 |
|-------------|----------|--------------|---------|--------------|
| `#` | `#0x8000` | `mov edx, 0x8000` | 取 token 剩余部分转整数 | `LoadPtrImm(0x8000)` |
| `$` | `$al` | `mov [edx], al` | 取 token 剩余部分查寄存器表 | `StoreMem(AL)` |
| `$` (带逗号) | `$ al, @ebx,esi` | SIB 寻址存储 | 继续读 `,` 后的 `@...` 表达式 | `StoreSIB(AL, EBX, ESI, 1, 0)` |
| `~` | `~eax` | `mov eax, [edx]` | 取 token 剩余部分查寄存器表 | `LoadMem(EAX)` |
| `~` (带逗号) | `~ eax, @ebp,edi,4` | SIB 寻址加载 | 继续读 SIB 表达式 | `LoadSIB(EAX, EBP, EDI, 4, 0)` |
| `=` | `=ebx` | `mov ebx, edx` | 取 token 剩余部分查表 | `MovRegFromPtr(EBX)` |
| `%` | `%ebx` | `mov edx, ebx` | 取 token 剩余部分查表 | `MovPtrFromReg(EBX)` |
| `>` | `>` | `inc edx` | 没有额外 token | `IncPtr` |
| `<` | `<` | `dec edx` | 没有额外 token | `DecPtr` |
| `+` | `+` | `inc byte [edx]` | 没有额外 token | `IncMem` |
| `-` | `-` | `dec byte [edx]` | 没有额外 token | `DecMem` |
| `!` | `!loop` | `jmp loop` | 取 token 剩余部分作为标签名 | `Jmp("loop")` |
| `?` | `?Zdone` | `jz done` | 第二个字符是条件码，剩余是标签 | `Jcc(Z, "done")` |
| `?N` | `?NZdone` | `jnz done` | 第二个字符是 `N`，第三个是条件码 | `JccNeg(Z, "done")` |
| `@` | `@label:` | 标签定义 | 去掉 `@` 和 `:`，记录当前地址 | `Label("label")` |


## ModRM 字节编码规则

| 位域 | 宽度 | 含义 | 示例值 |
|------|------|------|--------|
| mod (bits 7-6) | 2 bits | 寻址模式: 00=无位移 01=disp8 10=disp32 11=寄存器 | `00` |
| reg (bits 5-3) | 3 bits | 寄存器操作数编码 | `000` = AL/AX/EAX |
| r/m (bits 2-0) | 3 bits | 寄存器/内存操作数编码 | `010` = DX/EDX |

**µASM 中最常用的 ModRM 组合:**

| 指令 | mod | reg | r/m | 字节值 | 含义 |
|------|-----|-----|-----|--------|------|
| `$al` (store AL to [DX]) | 00 | 000 (AL) | 010 (DX) | `0x02` | `mov [edx], al` |
| `~eax` (load EAX from [DX]) | 00 | 000 (EAX) | 010 (DX) | `0x02` | `mov eax, [edx]` |
| `=ebx` (DX→EBX) | 11 | 011 (EBX) | 010 (DX) | `0xDA` | `mov ebx, edx` |
| `%ebx` (EBX→DX) | 11 | 010 (DX) | 011 (EBX) | `0xD3` | `mov edx, ebx` |
| `push ebx` | 11 | 110 (push) | 011 (EBX) | `0xF3` | `push ebx` |


## 重定位表原理

| 字段 | 含义 | 示例 |
|------|------|------|
| `offset` | 这条引用在输出缓冲区的位置 | `0x05` |
| `size` | 占用几个字节 | `4` (32位模式) 或 `2` (16位) |
| `label` | 引用的标签名 | `"read_error"` |
| `relative` | 是相对跳转(1)还是绝对地址(0) | `1` (jmp/call是相对的) |
